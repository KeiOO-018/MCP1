# Project ICI — 이전 프로젝트 분석

이 폴더는 **Project ICI**(2025.06.23 ~ 2025.09.11)를 UE 5.8에서 다시 만들기 위해
발표 자료를 판독해 정리한 것이다. MCP1 프로젝트의 참고 자료이며, 이 폴더 자체는
게임 애셋이 아니다.

## 자료 출처

- 원본: `Project ICI 게임 소개 PDF.pdf` — 85페이지, 9.4MB
- **원본 PDF는 저장소에 커밋하지 않는다.** `.gitignore`로 제외했다.
  파일은 이 폴더에 로컬로만 존재한다. 없어지면 요약본의 근거를 확인할 수 없다

## 어떻게 읽었는가 — 재현 방법

`Read` 도구의 PDF 렌더링은 `pdftoppm`(poppler)이 없어 실패했다. 두 가지로 우회했다.

1. **텍스트** — Git for Windows에 동봉된 `pdftotext`
   `pdftotext -layout -enc UTF-8 "<pdf>" out.txt`
2. **이미지** — poppler의 `pdfimages`가 없어서 의존성 없는 추출 스크립트를 직접 썼다.
   UE 5.8 동봉 Python 3.11로 실행
   (`C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\ThirdParty\Python3\Win64\python.exe`).
   PDF의 간접 객체와 객체 스트림(ObjStm)을 풀어 페이지 트리를 걷고,
   각 페이지의 `/Resources → /XObject`에서 이미지 스트림을 꺼내
   DCTDecode는 `.jpg` 그대로, FlateDecode는 PNG로 다시 감쌌다.

결과: 238장 추출 → 중복(템플릿 배경·로고) 제거 후 100장 → 실질 스크린샷 70장.
**그 70장을 전부 판독했다.** 블루프린트 노드 이름과 핀 값까지 읽힌다.

추출물은 스크래치패드에 있고 세션이 끝나면 사라진다. 다시 필요하면 위 절차를 반복한다.

## 이 문서들의 규칙

각 문서는 두 층으로 나뉜다. 섞지 않는다.

- **`자료에 있는 것`** — 슬라이드와 스크린샷에서 실제로 확인한 것. 추측 없음
- **`다시 만들면` (내 의견)** — 재설계 지점. 사용자가 쓴 게 아니라 AI가 본 것
