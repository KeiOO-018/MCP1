# Docs/Terminal-Log

UE Terminal이 명령을 수행하고 낸 **보고 원문**을 모아두는 곳이다.
`Docs/AI-Log/`가 "무엇을 왜 했는가"라면 여기는 "터미널이 뭐라고 말했는가"다.

## 왜 파일로 받는가

**화면 붙여넣기는 터미널 폭에서 잘리고, 잘린 조각이 원문 행세를 한다.**

2026-08-29에 이 방식으로 바꿨다. 그날 기록(`Docs/AI-Log/2026-08-29-inventory-hold-use-hud.md`)의
`총평`에 근거가 적혀 있다. 2026-09-03에 그 실패가 원문으로 다시 잡혔다 —
터미널이 명령 11의 보고를 다 찍었는데 복사 과정에서 `"A third"` 한복판에서 잘렸고,
터미널이 그것을 이렇게 짚었다.

```
Also worth naming: your message is a truncated fragment of my own previous
report — it stops mid-sentence at "A third".
```

## 파일이 두 종류다. 섞지 않는다

### 1. 실시간 기록 — 이 폴더 바로 아래

`YYYY-MM-DD-NN-slug.md`

명령을 낼 때 명령문 안에 아래 줄을 넣어서 **터미널이 직접 쓴 것**이다.

```
Write the report to Docs/Terminal-Log/YYYY-MM-DD-NN-slug.md
(a repo path - do NOT write under Saved/, it is gitignored).
```

- `NN`은 **연속 번호다. 세션마다 리셋하지 않는다**
- 그 자리에서 확보한 원문이다. 이게 기본이고 `CLAUDE.md`가 요구하는 방식이다

### 2. 소급 회수분 — `recovered/` 하위 폴더

`YYYY-MM-DD-<세션ID 8자>-recovered.md`

**실시간으로 안 받아서 나중에 되찾은 것이다.** 성격이 다르므로 폴더를 갈랐고,
**번호를 안 붙인다** — 번호는 실시간 기록의 계보다.

각 파일 머리에 회수 표시 블록이 있다. 출처 파일, 원본 크기, 세션 범위,
`isCompactSummary` 개수, 뽑은 블록 수가 적혀 있다.

## 회수는 어떻게 하는가

UE Terminal은 Claude Code 세션이다. **그 세션의 대화 기록이 로컬에 남는다.**

```
~/.claude/projects/d--20260827-MCP1/<세션 GUID>.jsonl
```

내(대화 쪽) 세션과 터미널 세션이 **같은 디렉터리에 섞여 있다.** 파일명으로는 안 갈린다.
**첫 사용자 메시지가 한글이면 나, 영어 명령이면 터미널이다.** 2026-09-03에 47개를
이 기준으로 갈랐고 예외가 없었다.

주의할 것 셋.

- **UTF-8로 읽어야 한다.** Windows PowerShell 5.1의 `Get-Content`는 기본이 ANSI라
  `×`가 `횞`로, `—`가 `??`로 깨진다. `-Encoding UTF8`을 붙인다
- **`.ps1` 스크립트에 한글을 쓰면 BOM이 필요하다.** BOM 없는 UTF-8 스크립트를
  PowerShell 5.1이 ANSI로 읽어 파서가 죽는다
- **`isCompactSummary`를 먼저 센다.** 대화가 압축된 구간이 있으면 그만큼 요약만 남는다.
  2026-09-03 기준 47개 전부 `0`이었다

뽑는 범위는 **사용자 메시지 텍스트와 터미널 응답 텍스트만**이다. 도구 호출과 반환값은
뺀다 — 실시간 파일이 담는 것이 "화면에 찍힌 보고"이므로 범위를 맞춘 것이다.
도구 호출까지 필요하면 원본 `.jsonl`을 직접 읽는다.

## 회수가 실시간 기록을 대신하지 못하는 이유

**되찾을 수 있으니 규칙을 안 지켜도 된다는 뜻이 아니다.**

- `.jsonl`은 **저장소 바깥**이다. 지워지면 끝이고 다른 PC엔 없다.
  이 폴더가 존재하는 이유가 "저장소에 남기는 것"이다
- 회수분은 **날것**이다. 실시간 파일은 터미널이 보고서로 정리해서 쓴 것이라
  어느 명령의 결과인지 바로 읽힌다
- 회수는 **세션이 끝난 뒤에야 가능하다.** 작업 중에 어긋남을 잡으려면 그 자리에 있어야 한다

## 지금 있는 것

| 종류 | 범위 | 개수 |
|---|---|---|
| 실시간 | 2026-08-29 (`NN` 시작) ~ 2026-08-30 (`42`) | 26 |
| 실시간 | 2026-09-03 (`43`) | 1 |
| 소급 회수 | 2026-08-31 ~ 2026-09-03 터미널 세션 8개 | 8 |

**2026-08-31부터 2026-09-03까지 규칙이 `CLAUDE.md`에 없어서 조용히 사라졌었다.**
그 구간이 `recovered/`의 여덟 파일이다. 2026-09-03에 규칙을 `CLAUDE.md`에 넣었다.

`2026-08-27`·`2026-08-28`과 `2026-08-29`/`2026-08-30`의 나머지는 회수하지 않았다.
앞의 둘은 규칙이 생기기 전이고, 뒤의 둘은 실시간 파일이 이미 있다.
