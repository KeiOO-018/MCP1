# AI 작업 기록 (AI-Log)

MCP 플러그인을 통해 AI에게 작업을 시키고, **그 결과를 분석해 내 역량으로 옮기기 위한** 기록입니다.
"AI가 뭘 해줬다"가 아니라 **"그래서 내가 뭘 알게 됐다"** 를 남기는 게 목적입니다.

---

## 보는 법

이 파일들은 마크다운입니다. VS Code에서 파일을 열고 **`Ctrl+Shift+V`** 를 누르면
제목·표·코드가 웹페이지처럼 렌더링됩니다. 편집 화면의 `#`, `|` 기호는 원본에서만 보입니다.

GitHub에 올리면 웹에서 자동으로 렌더링되므로, 나중에 링크 하나로 공유할 수도 있습니다.

---

## 규칙

### 1. 세션 전에 커밋한다

> **MCP에 명령을 내리기 전에 반드시 커밋한다.**

그러면 작업 후 `git status` 자체가 "AI가 무엇을 건드렸는가"의 증거가 됩니다.
사후에 추정할 필요도, 별도로 기록할 필요도 없습니다.
라이브 에디터를 AI에게 맡기는 작업에서는 이게 안전장치이자 기록 도구입니다.

실전 프로젝트(ICIProject 등)에 적용할 때는 선택이 아니라 **필수**입니다.

### 2. 명령 원문을 그대로 남긴다

프롬프트도 역량입니다. 나중에 "어떤 표현이 좋은 결과를 냈나"를 비교할 유일한 자료입니다.
다듬지 말고 실제로 입력한 문장 그대로 붙여넣습니다.

### 3. "혼자 할 수 있는가"를 반드시 채운다

각 기록의 마지막 항목입니다. ❌ 가 남으면 그게 다음 학습 대상입니다.
이 항목이 없으면 기록은 그냥 체인지로그가 됩니다.
